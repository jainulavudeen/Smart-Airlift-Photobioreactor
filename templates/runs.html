How runs work

  • Only one run can be active at a time.
  • Every temperature reading, lighting event and alert recorded while a run is active is tagged with its run ID.
  • Duration is calculated from start to stop (or to now while running).
  • Runs started in simulation mode are labelled SIMULATED so they are never confused with real experiments.
